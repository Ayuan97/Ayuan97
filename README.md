### 03 · 怎么读这个账号

```
public  ──────────────►  能 star 的、能 fork 的、能喷的
private ──────────────►  还在长、或暂时不想被搜索引擎索引的
forks   ──────────────►  路过抄作业（hermes / vibe-island 一类）
```

如果你是来找「干净的开源 portfolio」——可能走错片场。  
如果你是来找「有人真的在碰 HV / DMA / game stack / Agent」——那就对上了。
